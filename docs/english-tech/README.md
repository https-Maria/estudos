# Technical English

Inglês aplicado ao que já está sendo construído em SQL Server e Data Lake.

## Objetivo

Parar de estudar gramática isolada e usar inglês para:
- documentação;
- incident reports;
- READMEs;
- runbooks;
- architecture walkthroughs;
- troubleshooting;
- entrevistas;
- explicação oral de projetos.

## Regra

Cada módulo de inglês deve reutilizar conteúdo técnico real dos projetos.

Exemplo:

> There are three processing layers in this data lake: Bronze, Silver, and Gold.

> The NiFi flow is consuming data from the Bitrix API.

> I restored the database to a point before the accidental deletion.

## Template
```md
# Topic

## Rule / shortcut
## My examples
## Mistakes I made
## Corrected version
## Technical vocabulary
## Production exercise
```
