# SQL DBA Lab

Laboratório permanente de SQL Server para estudo de DBA + DP-300.

## Regras
- Tudo destrutivo acontece somente no ambiente de laboratório.
- Cada módulo gera um artefato técnico.
- Break & Fix deve registrar: sintoma → investigação → causa → correção → validação.
- Sempre registrar evidências antes/depois quando houver performance.

## Estrutura sugerida
1. Build do laboratório
2. Transactions
3. Indexes & Execution Plans
4. Blocking
5. Deadlocks
6. Performance incident
7. Backup & Restore
8. Security
9. Automation
10. Break & Fix Day
11. HA / DR
12. Final case
