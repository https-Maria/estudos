# Portfolio Roadmap

O portfólio cresce junto do estudo. Não é uma quarta matéria.

## Projeto 1 — SQL DBA Lab

**Resultado final:** laboratório SQL Server populado, com transações, incidentes, tuning, backup/restore, segurança, automação e decisões HA/DR.

## Projeto 2 — Bitrix Data Lake

**Resultado final:** case técnico de ingestão Bitrix → NiFi → S3 → Glue/PySpark → Athena, com Bronze/Silver/Gold, qualidade, orquestração e governança.

## Projeto 3 — Technical English

**Resultado final:** documentação técnica bilíngue e capacidade de explicar os dois projetos em inglês.

## Regra de publicação

Portfólio público deve conter somente dados sintéticos, anonimizados ou produzidos no laboratório. Nenhum segredo ou informação confidencial da empresa deve ser versionado.
